轻解析 · 云端版

手机随时用，不靠电脑

后端跑在 GitHub 的免费算力上。粘贴链接 → 云端下载 → 给出直链。首次需填一次 Token。

一次性设置：GitHub Token
生成（约 40 秒）：GitHub → Settings → Developer settings → Personal access tokens (classic) → Generate new token → 勾选 repo 和 workflow → 生成后粘贴到这里。
只存在你手机浏览器本地（localStorage），不会上传到任何第三方。
限制（先说清楚）
· 每个任务要排队 1–3 分钟（GitHub 免费 runner 的启动时间），不是秒出；
· GitHub 的出口是数据中心 IP，YouTube 有可能要人机验证，B站/优酷受地区限制（国内站需代理）；
· 产出放在 Release，任何人都拿得到链接（仓库公开时），所以别下隐私内容。
